# CU Stats HUD

> 一只FOX做的状态监护面板。
>
> 游戏里那些藏得很深的数字——心跳、血压、哪条腿在流血、还能撑多久——现在全摊在一块
> 像医院监护仪的面板上，抬眼看得到，不用再翻菜单翻到手酸。

## 装一下

1. 装好 [BepInEx 5.4.x](https://github.com/BepInEx/BepInEx/releases)（x64）。
2. 把 `CUStatsHud.dll` 丢进游戏目录的 `BepInEx\plugins\`。
3. 开游戏，按 N 键打开

三步，比给尾巴打结简单...

> 需要 BepInEx 自带的 `0Harmony.dll`（装 BepInEx 就有）。
> 联机 MOD（Krokosha）**不是必需**——单机一样能用，只是联机时才会多出队友那一页。

## 关于那些数字

- 全部直接读游戏的 `Body` / `Limb` / `Skills`，**不是估算**——狐狸不编数字。
- 显示口径跟着游戏自己的医疗面板（`WoundView`）走：辐射剂量 = `radiationSickness × 0.3` gy、
  体重 = `weightOffset × 0.34 + 50` kg、流血速率 = `bloodToLiters(总流血速度) × 60` l/m。
- 变红的阈值取自游戏自身的 `isDying` / `isCriticallyDying`——面板红起来，说明游戏内部也认为你快不行了。
- 距离按 **1 世界单位 = 1 米** 算。依据是游戏没改过 `Physics2D.gravity`（仍是 Unity 默认值），
  而且方块与世界坐标是 1:1 映射。这是推断，不是源码明文写的，先说明白。

**呼吸波为什么看着一直一样？** 因为游戏根本没给出呼吸曲线——心电有，呼吸没有。
这条波形只能反映两件事：还在不在呼吸（停了会变成一条直线）、呼吸频率（决定周期快慢）。
频率平时基本恒定，所以形状稳定是**符合事实**的，它不像心电那样有真实起伏。这一点不打算糊弄过去。

## 统计页

记性这东西靠不住，所以让插件替你记：挖了多少方块、用了几次什么道具、做了什么、走了多远、升到几级。

- **全在本机**：写在 `BepInEx/config/CUStatsHud.stats.dat`，加密保存。不联网、不上报、不带任何身份信息。
- 加密是 AES-256-CBC，密钥由插件标识和固定盐经 PBKDF2 派生。这是「防随手翻看、防手改存档」的级别，
  **不是防逆向**——能反编译的人依旧解得开。这点也先讲清楚。
- 重置要**连点两次**才会真清空，没有撤销。

## 自定义外观

设置页「显示」区里，「界面风格」三选一：**原版** / **游戏风格** / **自定义**。

**自定义配色**只调三个滑块，其余全自动派生：

| 滑块 | 管什么 |
|---|---|
| 色相 | 整体色调（红 / 绿 / 蓝紫 / 品红……） |
| 底色明度 | 面板明暗（始终留在深色区间，不会变成刺眼的白界面） |
| 强调强度 | 强调色有多鲜艳，顺带影响底色的冷暖 |

底色饱和度被压在低区间、文字几乎不着色，所以**很难调出没法看的组合**——这是故意的。
滑块下面有四格实时预览（面板 / 卡片 / 描边 / 强调色）。

**自定义底图**：点「选择底图…」会打开**游戏内的文件浏览器**（不是系统对话框）。

> 为什么不用系统的 `OpenFileDialog`：Unity 的 Mono 运行时不保证满足 WinForms 的 STA 线程要求，
> 实测在游戏里拉不起来。所以改成在插件自己的界面里浏览文件系统——用的就是插件已有的读文件权限，
> 不牵扯额外的线程和窗口，踏实得多。

浏览器能切驱动器、进子目录，右侧有**实时预览**（连图片尺寸一起显示）。列表只列 png / jpg / jpeg / bmp，
压缩包之类的根本不会冒出来；点「使用这张图」之前还会再核一次扩展名。

选好后图片会被复制到 `BepInEx\config\CUStatsHud-bg.<扩展名>` 统一管理——之后挪走或删掉原图都不影响。
滑块调透明度（**最低 1%**，右侧实时显示百分比）；旁边的「显示底图」开关可以随时关掉，
图片和浓度都会留着，下次打开还是原来的样子。

## 配置

改 `BepInEx/config/com.fox.custatshud.cfg`，或者在游戏里调。常改的就这几个：

| 键 | 默认 | 说明 |
|---|---|---|
| `Keys/Toggle` | `N` | 显示/隐藏面板 |
| `Keys/FloatToggle` | `F2` | 组件卡 |
| `UI/Scale` | `1.0` | 整体缩放（0.7 ~ 1.5） |
| `UI/FontSize` | `15` | 字号（11 ~ 20） |
| `UI/FontMode` | `auto` | 字体来源：`auto` / `system` / `game` |
| `UI/Skin` | `fox` | `fox`（原版 UI）/ `game`（纯黑 + 纯白边框）/ `custom`（自定义） |
| `UI/ShowEmoji` | `true` | 关掉后不显示任何装饰图标 |
| `Theme/Hue` | `0.62` | 自定义配色的色相 |
| `Theme/Dark` | `0.35` | 自定义配色的底色明度 |
| `Theme/Saturation` | `0.5` | 自定义配色的强调强度 |
| `Theme/BackgroundEnabled` | `true` | 是否显示底图（关掉后保留图片） |
| `Theme/BackgroundOpacity` | `0.35` | 底图透明度（1% ~ 100%） |
| `Monitor/ShowNormalSecondary` | `false` | 次要指标是否常显（默认只在异常时露头） |

其余键的含义，配置文件里每条都写了。

## 可能会问

**面板挡着玩游戏怎么办？** 面板是直接画在屏幕上的一层，点它也会点到游戏。
把它挪到不碍事的角落，或者干脆只在需要时按 `N` 叫出来（默认就是藏着的）。

**绑快捷键那一下为什么游戏也动了？** 因为那一次按键同时传给了游戏。绑好之后就不影响了。

**换了显示器，面板跑哪去了？** 会自动夹回屏幕里，不会跑到外面去。

**游戏字体缺字、看着一笔粗一笔细？** 字体有「自动 / 系统 / 游戏」三档，
`auto` 会在游戏字体字形不够时自动退回系统字体——那种粗细混排通常是缺字回退造成的。

## 从源码编译（实在不行，你去直接拿编译好的文件得了）

```bash
# 需要 .NET SDK，以及游戏本体的 Assembly-CSharp.dll
dotnet build CU-Stars-Hub.csproj -c Release -p:GameDir="你的游戏根目录"
# 产物：bin/CUStatsHud.dll
```

`GameDir` 默认指向 Steam 的安装位置，用 `-p:GameDir=` 可以覆盖。

## 已知限制（老实 quq）

- 覆盖层会「点击穿透」到游戏——这是直接绘制方案的固有限制，不是偷懒。
- 呼吸波是示意波形，游戏没给这个数据，详见上文。
- 界面文案只有中文，没做多语言。
- 只在 16:9 / 21:9 / 4:3 的常见分辨率上验过布局，极端宽高比没实测。
